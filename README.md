# 🔐 PDF Password Recovery & Hash Analysis Lab

About the Project

This repository documents three progressive practical exercises completed as part of my cybersecurity internship training.

The project focuses on PDF password recovery, hash extraction, hash analysis, and password auditing using NetworkWalks tools and John the Ripper.

All three exercises followed the same core process, with each task increasing in difficulty. I worked with NetworkWalks Hash Calculator to extract and analyze PDF hashes and used John the Ripper for password recovery. I also explored Johnny GUI, the graphical interface for John the Ripper.

Objectives

- Understand password-protected PDF files.
- Extract hashes from PDF files.
- Understand PDF hash formats.
- Explore hash calculation and analysis.
- Learn password recovery techniques.
- Work with NetworkWalks password security tools.
- Gain practical experience with John the Ripper.
- Explore Johnny GUI.
- Complete three progressive password recovery challenges.

Practical Workflow

The following workflow was applied across all three tasks:

1. Obtain the password-protected PDF provided for the exercise.
2. Use NetworkWalks Hash Calculator to extract the PDF hash.
3. Understand and examine the extracted hash format.
4. Use the available password recovery tools, including NetworkWalks and John the Ripper.
5. Perform password recovery within the authorized lab environment.
6. Verify the recovered password by opening the protected PDF.
7. Record the results and document the exercise.
