# Cybersecurity-Project-John-the-Ripper-Lab
Hands-on password security lab using John the Ripper and Johnny GUI, documenting three practical exercises in an authorized educational environment.
Week 3 - Password Security Lab with John the Ripper

Overview

This repository documents my Week 3 cybersecurity internship lab focused on understanding password security and password recovery using John the Ripper and its graphical interface, Johnny.

The exercises were performed in an authorized educational lab environment using provided test files.

Objectives

- Understand password security and password recovery concepts.
- Explore John the Ripper and Johnny GUI.
- Learn about password hash formats and password auditing.
- Observe the lab workflow and document the results.
- Understand the importance of strong passwords and secure storage.

Tools Used

- John the Ripper Jumbo
- Johnny GUI 2.2
- Windows
- Kali Linux

Lab Exercises

PM1 - Password Cracking with John the Ripper

Completed the three provided lab exercises using the assigned test files.

PM2 - Password Cracking with NetworkWalks Tools

Completed the password-recovery exercise using the browser-based NetworkWalks tools.

Key Learnings

- Password security depends on the strength and complexity of passwords.
- Password hashes are different from plaintext passwords.
- Weak or predictable passwords can be vulnerable to dictionary-based guessing.
- Tool configuration and correct identification of hash formats are important in security testing.
- Password auditing should only be performed with explicit authorization.
